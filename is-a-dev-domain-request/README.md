# Getting taiwoatlas.is-a.dev

This folder is NOT part of the website — it's the one file you need to submit
to get the free `taiwoatlas.is-a.dev` domain.

## Steps

1. Fork this repo: https://github.com/is-a-dev/register
2. In your fork, add the file `domains/taiwoatlas.json` using the content of
   `taiwoatlas.json` in this folder — but first replace `YOUR_GITHUB_USERNAME`
   with your actual GitHub username.
3. Commit, then open a pull request back to `is-a-dev/register`.
   A bot will validate it automatically. If it passes, it's usually merged
   within a day or two — no action needed from you beyond that.
4. Once merged, go to your Vercel project → Settings → Domains → add
   `taiwoatlas.is-a.dev` → follow Vercel's verification prompt (it will just
   confirm the CNAME is pointing correctly, which it already will be).

That's it — no renewal, no cost, no expiry.
